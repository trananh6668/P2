    1. Phân Loại 5 Nhóm Lệnh Trong SQL

    DQL Data Query Language (Truy vấn)

    Lấy dữ liệu từ một hoặc nhiều bảng mà không làm thay đổi trạng thái dữ liệu.

    SELECT DISTINCT Lop, QueQuan FROM SinhVien WHERE HocBong > 0 ORDER BY HoTen ASC;

    DML Data Manipulation Language (Thao tác)

    Thêm mới, cập nhật hoặc xóa các bản ghi (dòng dữ liệu) trong bảng.

    INSERT INTO Khoa VALUES ('DTVT', 'Điện tử Viễn thông', 'C7'); UPDATE SinhVien SET HocBong = 5000000 WHERE MaSV = 101; DELETE FROM DangKyHoc WHERE Diem IS NULL;

    DDL Data Definition Language (Định nghĩa)

    Tạo, sửa cấu trúc bảng, xóa bảng hoặc làm rỗng toàn bộ bảng.

    CREATE TABLE LopHoc (MaLop VARCHAR(10) PRIMARY KEY); ALTER TABLE SinhVien ADD Email VARCHAR(100); TRUNCATE TABLE TamThoi; -- Xóa sạch dòng, giữ cấu trúc DROP TABLE TamThoi; -- Xóa vĩnh viễn cả bảng

    DCL & TCL Phân Quyền & Giao Dịch

    Kiểm soát quyền truy cập (DCL) và tính toàn vẹn giao dịch (TCL - ACID).

    -- DCL: Cấp và thu hồi quyền GRANT SELECT, INSERT ON SinhVien TO user_gv; REVOKE INSERT ON SinhVien FROM user_gv; -- TCL: Quản lý Transaction BEGIN TRANSACTION; UPDATE TaiKhoan SET SoDu = SoDu - 100 WHERE ID = 1; COMMIT; -- Hoặc ROLLBACK nếu có lỗi xảy ra

    4. Biểu Thức Điều Kiện CASE WHEN & Xử Lý NULL

    CASE WHEN hoạt động tương tự cấu trúc if - else if - else trong lập trình, cho phép phân loại dữ liệu ngay trong câu truy vấn.

    SELECT sv.HoTen, dk.Diem, CASE WHEN dk.Diem >= 8.5 THEN 'Giỏi (A)' WHEN dk.Diem >= 7.0 THEN 'Khá (B)' WHEN dk.Diem >= 5.0 THEN 'Trung bình (C)' WHEN dk.Diem IS NULL THEN 'Chưa có điểm' ELSE 'Trượt môn (F)' END AS XepLoai FROM SinhVien sv LEFT JOIN DangKyHoc dk ON sv.MaSV = dk.MaSV;

    Quy Tắc Vàng Với Giá Trị NULL

    • NULL không phải là số 0 hay chuỗi rỗng '' — nó đại diện cho giá trị chưa xác định.
    • Không bao giờ viết WHERE Diem = NULL (luôn trả về rỗng). Phải dùng WHERE Diem IS NULL hoặc IS NOT NULL.
    • Dùng COALESCE(Diem, 0) hoặc IFNULL(Diem, 0) để thay thế NULL bằng giá trị mặc định khi tính toán.

    5. Truy Vấn Nâng Cao: Subquery, CTE & Window Functions

    A. Subquery (Truy vấn lồng nhau)

    Câu lệnh SELECT nằm bên trong một câu lệnh SELECT khác (trong WHERE, FROM hoặc SELECT).

    -- Tìm sinh viên có điểm cao hơn điểm trung bình toàn trường SELECT * FROM DangKyHoc WHERE Diem > (SELECT AVG(Diem) FROM DangKyHoc);

    B. CTE (Common Table Expression - Bảng tạm WITH)

    Giúp chia nhỏ câu truy vấn phức tạp thành các khối logic dễ đọc và tái sử dụng nhiều lần.

    WITH ThongKeSV AS ( SELECT MaSV, AVG(Diem) AS DiemTB FROM DangKyHoc GROUP BY MaSV ) SELECT sv.HoTen, tk.DiemTB FROM SinhVien sv JOIN ThongKeSV tk ON sv.MaSV = tk.MaSV WHERE tk.DiemTB >= 8.0;

    C. Window Functions (Hàm Cửa Sổ - Cực kỳ quan trọng trong phân tích dữ liệu)

    Khác với GROUP BY (gộp nhiều dòng thành 1 dòng), Window Function giữ nguyên từng dòng chi tiết và tính toán trên một "cửa sổ" phân vùng dữ liệu.

    SELECT MaSV, MaMH, Diem, ROW_NUMBER() OVER (PARTITION BY MaMH ORDER BY Diem DESC) AS HangTheoMon, RANK() OVER (PARTITION BY MaMH ORDER BY Diem DESC) AS XepHangDongHang FROM DangKyHoc;

    2. Trực Quan Hóa Đầy Đủ 5 Loại Phép Nối Bảng (SQL JOINS)

    INNER JOIN

    Chỉ lấy phần giao khớp nhau ở cả 2 bảng.

    A INNER JOIN B ON A.id = B.id
    LEFT JOIN

    Toàn bộ bảng trái A + phần khớp của B (không khớp = NULL).

    A LEFT JOIN B ON A.id = B.id
    RIGHT JOIN

    Toàn bộ bảng phải B + phần khớp của A (không khớp = NULL).

    A RIGHT JOIN B ON A.id = B.id
    FULL OUTER JOIN

    Lấy tất cả bản ghi từ cả 2 bảng A và B.

    A OUTER JOIN B ON A.id = B.id
    LEFT ANTI JOIN

    Chỉ lấy dòng ở A mà KHÔNG có ở B (tìm dữ liệu thiếu).

    ... WHERE B.id IS NULL
